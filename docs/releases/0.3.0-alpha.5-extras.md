## Quill UI Extras - 0.3.0-alpha.5

World-anchored speech bubbles.

### Added

- `QuillSpeechBubble`: one bubble with a stable key, world position, text, accent colour, range and
  a through-walls flag.
- `QuillSpeechBubbleSource`: supplies the bubbles for the current frame.
- `QuillBubbleHud`: generic `HudElement` that projects the bubbles onto the screen, smooths their
  movement, fades them by distance, handles occlusion and draws a themed bubble with a tail.
  Register it with Fabric's `HudElementRegistry` and supply the theme with a `Supplier`.

### Notes

- The bubble uses the theme roles `PANEL_BG`, `TEXT`, `PANEL_SHADOW`; the border uses each bubble's
  accent colour. It works with any `QuillThemeData`.
- The shadow is a soft 2 px offset, not a hard plate.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.5.jar`
- Requires the Quill UI core jar `0.3.0-alpha.5` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
