## Quill UI core - 0.3.0-alpha.5

Compatibility release for the `0.3.0-alpha.5` extras.

### Notes

- No core API changes; `API_LEVEL` remains `3`.
- Keeps the header accessories, chips, button icons and measured content line from `alpha.4`.

### Install

- Jar: `quill-ui-0.3.0-alpha.5.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
