## Quill UI Extras - 0.3.0-alpha.3

Compatibility release for the `0.3.0-alpha.3` core.

### Changed

- Rebuilt against the `0.3.0-alpha.3` core metadata.
- No functional changes to `QuillMap` or the HUD indicator.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.3.jar`
- Requires the Quill UI core jar `0.3.0-alpha.3` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
