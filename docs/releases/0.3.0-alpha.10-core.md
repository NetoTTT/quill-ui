## Quill UI core - 0.3.0-alpha.10

Toast stacking.

### Fixed

- Multiple `QuillToast` overlays used to paint at the same top-right position and covered each
  other. The overlay stack now measures each open toast and offsets it below the previous one,
  so a burst of notifications stays readable.

### Notes

- Additive/fix release; `API_LEVEL` remains `3`.

### Install

- Jar: `quill-ui-0.3.0-alpha.10.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
