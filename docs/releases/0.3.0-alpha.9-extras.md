## Quill UI Extras - 0.3.0-alpha.9

Map connector lines.

### Added

- `QuillMapPath(from, to, color)` plus `QuillMap.setPaths/addPath/paths`: thin lines drawn in
  block space, so overlays pan and zoom with the map. Rendering happens above zones and below
  selection/markers.
- Useful for fence outlines, routes, pipes or any structure that is not a rectangle.

### Notes

- Additive release; `API_LEVEL` remains `3`.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.9.jar`
- Requires the Quill UI core jar `0.3.0-alpha.9` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
