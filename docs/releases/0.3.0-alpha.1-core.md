## Quill UI core - 0.3.0-alpha.1

The ergonomics line. This alpha keeps the measured layout engine and focus work from 0.2 and breaks
the static theme facade so screens can be built from measured trees instead of magic coordinates.

### Breaking changes

- `API_LEVEL` is now `3`.
- `QuillTheme` was removed. Use `QuillThemeData` roles (`theme.color(ColorRole.X)`) and
  `QuillThemeScope` for screen-inherited themes.
- `QuillActionSink` is generic: `QuillActionSink<String>` replaces the old untyped interface.
  `QuillCommandSink` is the command-first `QuillActionSink<String>`.
- `QuillMap` and `com.quillui.hud` moved to the optional add-on jar; they are its current contents,
  not a fixed scope.
- `QuillTheme.SPACE_*` aliases are gone; use `QuillSpacing`.

Migration details are in `docs/06-MIGRATION.md`.

### Measured content trees

- `QuillScreen.setContent(root)` measures and arranges a tree in the content area, registers its
  widgets and adds a scroll host automatically when it overflows.
- `setContent(root, bounds)` reserves space for fixed footer controls.
- `control(widget)`, `control(widget, height)`, `text(component)` and `text(component, role)` build
  tree leaves without coordinates.
- `refreshContent()` rebuilds on the next tick after local state changes and preserves the content
  scroll offset.
- `contentScrollOffset()` / `contentMaxScroll()` expose the scroll state for hints.

### Widgets and builders

- `QuillListView<T>`: node-based rows with real widgets, item selection, scroll preservation and
  mouse/key routing.
- `QuillNodes`: `row`, `column`, `flexible`, `spacer`, `sized`, `fixedWidth`, `fixedHeight`, `widget`
  and `tabs`.
- `QuillCardBox`: measured card with an optional heading and a padded child tree.
- `QuillTextNode` and `QuillLabel` measure wrapped text through `Font`.
- `QuillButtonStyle`, `QuillButton.enabled(...)` and fluent label styles.
- Row builders are scoped to the list theme, so lazy widgets use the correct light/dark palette.

### Theme

- `QuillThemeMetrics` carries control height, field/slider/button widths, row gap, content inset and
  card padding. The concise factories and screen helpers read them.
- Text, card padding and control sizes now follow the active theme.

### Fixes

- Layout sums saturate at `UNBOUNDED` instead of overflowing.
- The overlay dispatch is centralized in `QuillOverlayStack`.
- Text nodes render at the arranged width.
- Screen content builders run inside `QuillThemeScope`.

### Install

- Jar: `quill-ui-0.3.0-alpha.1.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
