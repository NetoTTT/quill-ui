## Quill UI core - 0.3.0-alpha.8

Headerless screen fix.

### Fixed

- `showHeader(false)` no longer draws the old title/subtitle block a second time outside the
  header condition. Headerless screens now really start at the navigator.

### Notes

- Additive/fix release; `API_LEVEL` remains `3`.

### Install

- Jar: `quill-ui-0.3.0-alpha.8.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
