## Quill UI core - 0.3.0-alpha.4

Header accessories and a compact chip for read-only values.

### Added

- `QuillScreen.headerAccessory()`: an optional measured node shown in the header, right-aligned
  before the close control. It is rebuilt with the content on resize and refresh.
- `QuillChip`: a compact read-only pill with optional icon, short text and theme colours
  (`muted`, `title`, `accent`, `color`). It is measured and never takes focus.

### Notes

- Additive release; no existing signature changed. `API_LEVEL` remains `3`.
- Header accessories are intended for short status values (balance, server name, counters).

### Install

- Jar: `quill-ui-0.3.0-alpha.4.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
