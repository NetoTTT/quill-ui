## Quill UI Extras - 0.3.0-alpha.1

Initial release of the optional add-on module for Quill UI. Extras hosts features that should not
weigh on the core; map and HUD are its current contents, not a fixed scope.

### Added

- `QuillMap`: interactive top-down world map with cached terrain tiles, drag selection, zones,
  markers, zoom and clipping inside Quill content hosts.
- `QuillTargetIndicator` and `QuillTargetIndicatorHud`: off-screen target ring, icon, chevron,
  distance label and theme-aware colours.
- Extras module icon.

### Changed

- `QuillMap` and the HUD indicator moved out of the core jar into this module. Their public classes
  keep the same package names and API.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.1.jar`
- Requires the Quill UI core jar `0.3.0-alpha.1` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
