## Quill UI Extras - 0.3.0-alpha.10

Compatibility release for the `0.3.0-alpha.10` core.

### Notes

- Rebuilt against the new core metadata; no map/HUD API changes.
- `QuillMapPath` from alpha.9 is unchanged.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.10.jar`
- Requires the Quill UI core jar `0.3.0-alpha.10` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
