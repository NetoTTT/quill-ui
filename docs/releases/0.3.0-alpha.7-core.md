## Quill UI core - 0.3.0-alpha.7

Fixed navigators and optional headers.

### Added

- `QuillScreen.navigator()`: an optional measured node rendered below the header and outside the
  scrolling content. Tabs stay fixed while the body scrolls.
- `QuillScreen.showHeader()`: screens can hide the title/subtitle band (inventory-style screens).

### Notes

- Navigator buttons are rebuilt with the content on resize/refresh, and their paintables stay fixed.
- Additive release; `API_LEVEL` remains `3`.

### Install

- Jar: `quill-ui-0.3.0-alpha.7.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
