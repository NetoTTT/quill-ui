## Quill UI Extras - 0.3.0-alpha.6

Layer-aware map clicks.

### Added

- `QuillMap.layerY()`: world Y of the visible layer (surface or the underground pivot). Hosts can
  turn a map click into a world position on the layer the player is looking at.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.6.jar`
- Requires the Quill UI core jar `0.3.0-alpha.6` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
