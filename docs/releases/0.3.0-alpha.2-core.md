## Quill UI core - 0.3.0-alpha.2

Maintenance alpha for screens that are still on absolute layouts.

### Added

- `QuillScreen.constrainPanel()` controls whether the panel shrinks to fit the viewport.
  Measured screens keep the default (`true`); legacy absolute screens can return `false` until their
  content is converted, avoiding compressed tabs, sections and slot grids.

### Notes

- No breaking public API changes; `API_LEVEL` remains `3`.
- The measured content API from `0.3.0-alpha.1` is unchanged.
- `QuillTheme` remains removed and map/HUD remain in the optional extras jar.

### Install

- Jar: `quill-ui-0.3.0-alpha.2.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
