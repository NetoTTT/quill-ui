## Quill UI core - 0.3.0-alpha.3

Button icons. Buttons can now show an item or a texture region instead of, or before, their label.

### Added

- `QuillIcon`: a small paintable glyph (`width`, `height`, `paint`) for custom button content.
- `QuillIcons.item(ItemStack)`: renders an item stack at its native 16x16 size.
- `QuillIcons.texture(texture, u, v, width, height, textureWidth, textureHeight)`: renders a
  texture region addressed in pixels.
- `QuillButton.icon(QuillIcon)`, `QuillButton.icon(ItemStack)` and `QuillButton.iconGap(int)`.
  Icons are centred; with a label they sit before the text, and disabled buttons dim the icon.

### Notes

- Additive release; no existing signature changed. `API_LEVEL` remains `3`.
- Icon-only buttons should get a tooltip, since the label may be empty.

### Install

- Jar: `quill-ui-0.3.0-alpha.3.jar`
- Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3 and Java 25.
