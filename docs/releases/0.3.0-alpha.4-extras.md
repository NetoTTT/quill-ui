## Quill UI Extras - 0.3.0-alpha.4

Merged zone rendering for the map.

### Added

- `QuillMap.setMergeZones(boolean)`: touching zones that share fill, border and dash style are
  painted as one region. Internal edges are skipped, so adjacent rectangles stop showing the
  lines that split a single area (useful when the server sends zones per chunk/section).

### Notes

- Groups are merged per style; a single zone keeps its normal (including dashed) rendering.
- Very large groups fall back to per-zone drawing to bound the work.

### Install

- Jar: `quill-ui-extras-0.3.0-alpha.4.jar`
- Requires the Quill UI core jar `0.3.0-alpha.4` or newer.
- Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API 0.164.0+26.3, Java 25.
- Client-side only. Dedicated servers do not need this jar.
