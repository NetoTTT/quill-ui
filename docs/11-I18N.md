# Internationalization

Quill UI does not define a second translation system. It uses Minecraft's language files and
`Component.translatable`, so a language change applies consistently to Quill and to the host mod.

## Mod language files

Create one JSON file per locale:

```text
src/main/resources/assets/<modid>/lang/en_us.json
src/main/resources/assets/<modid>/lang/pt_br.json
```

```json
{
  "mymod.config.title": "Configuration",
  "mymod.config.language": "Language",
  "mymod.config.save": "Save"
}
```

Use translation components instead of prebuilt strings:

```java
QuillButton save = new QuillButton(
        x, y, width, 20,
        Component.translatable("mymod.config.save"),
        QuillButton.Variant.PRIMARY,
        action
);
```

Widgets that take a `Component` keep the key alive; the text is resolved by the current language when
it is rendered. Do not call `Component.literal` for user-facing UI text.

## Runtime language selector

`QuillLanguage` lists the languages provided by the client and changes the active language through
Minecraft's `LanguageManager`.

```java
QuillLanguage.LanguageOption current = QuillLanguage.selected();
List<QuillLanguage.LanguageOption> languages = QuillLanguage.available();

QuillLanguage.setSelected("pt_br");
```

If a screen prebuilds literal labels or other non-translatable state, rebuild it after the resource
reload:

```java
QuillLanguage.setSelected("pt_br", MyConfigScreen::new);
```

The simple overload also reloads resources; screens made from translatable components can usually
just stay open.

## Config-screen pattern

A configuration screen can expose a language control without owning a translation registry:

```java
List<QuillLanguage.LanguageOption> languages = QuillLanguage.available();
QuillLanguage.LanguageOption current = QuillLanguage.selected();

QuillButton language = new QuillButton(
        x, y, width, 20,
        Component.translatable("mymod.config.language")
                .append(Component.literal(": " + current.name().getString())),
        QuillButton.Variant.SECONDARY,
        () -> {
            int index = languages.indexOf(current);
            QuillLanguage.LanguageOption next =
                    languages.get((index + 1) % languages.size());
            QuillLanguage.setSelected(next.code(), MyConfigScreen::new);
        }
);
```

The exact control can be a button, dropdown or future Quill selector. The contract is the locale
code and the standard `assets/<modid>/lang` convention.

## Rules

- Use `Component.translatable` for visible UI strings.
- Keep keys namespaced by mod, for example `mymod.config.title`.
- Provide at least `en_us.json`; missing keys fall back to the key or the vanilla fallback.
- Language changes are global, not per screen or per mod.
- Use `setSelected(code, factory)` when the screen must be rebuilt after the reload.
- Do not translate internal IDs, command names or network values.
